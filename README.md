# VisonCube Music for Windows

VisonCube Music 是面向 Windows 的音乐播放与管理客户端，提供搜索、播放、歌词、歌单、本地音乐、账号与多端同步等功能。

## 下载与更新

请从 [VisonCube Music Windows Releases](https://github.com/3298003230/VisonCube-Music-Windows/releases) 获取安装包与更新说明。应用内更新只使用 VisonCube Music 的发布信息。

## 移动端

Android 客户端位于 [VisonCube Music Android](https://github.com/3298003230/VisonCube-Music-Android)。

## 常用功能

- 管理本地歌单、历史与收藏；
- 使用自定义音源和托管音源；
- 登录账号后同步历史、歌单和配置；
- 支持歌词、桌面歌词、主题、快捷键和系统托盘；
- 可在设置中选择关闭时询问、隐藏到系统托盘或退出程序。
